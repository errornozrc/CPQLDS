# CPQLDS（C盘清理大尸）
CPQLDS（C盘清理大尸），由一位正在学习编程语言且研究Windows系统的学生写成（部分借助AI和网络）。由VBScript、BAT、C++编写。
这坨屎会删除你的系统文件和用户文件，把你的系统清理得干干净净[doge]。


# 实现方逝（简述，不想多说。。。）
本质上这个.exe就是个自解压程序，利用一些.bat、.vbs脚本实现提权、弹窗、删文件，最后再执行我用c++和BAT写的恶搞程序，完工！


# 屎（逝）用方法：
重点说，怕小白不会[doge]，用管理员身份执行程序，看到加载提示点确定，等待加载完成弹出向导一直点“确定”就好了，最后大概还会请你喝好喝的钙[doge]。。。
